# Student Profile Check

เว็บแอปสำหรับให้นักเรียน ม.1 และ ม.4 ตรวจสอบและแก้ไขข้อมูลของตนเอง โดยใช้ **ชั้น + ห้อง + เลขประจำตัวนักเรียน** ในการเข้าใช้งาน

## ความสามารถ

- นักเรียนตรวจสอบและแก้ไขข้อมูลของตนเอง
- ยืนยันข้อมูลแม้ไม่มีการแก้ไข
- บันทึกประวัติค่าก่อนแก้และหลังแก้ทุกครั้ง
- ครูดู Dashboard สรุปจำนวนผู้ตรวจสอบแล้ว / ยังไม่ตรวจ / มีการแก้ไข
- ค้นหาและกรองตามระดับชั้น ห้อง และสถานะ
- ดูประวัติการแก้ไขย้อนหลัง
- ส่งออก Excel โดยมีชีตข้อมูลล่าสุดและประวัติการแก้ไข
- Backend ใช้ Supabase Edge Function และ PostgreSQL
- ข้อมูลนักเรียนไม่ถูกเก็บไว้ใน GitHub repository
